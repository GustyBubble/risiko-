# Risiko-Tracker

Web-App zum Mitschreiben eines echten Risiko-Brettspiels am iPad – mit großer Auswertung am Ende.

Dieses Repo enthält nur das fertig gebaute Spiel für GitHub Pages.

**Aufs iPad:** Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Läuft danach im Vollbild und offline.
Spielstände bleiben nur auf dem jeweiligen Gerät (Backup über „Spiel exportieren“ im Menü).
